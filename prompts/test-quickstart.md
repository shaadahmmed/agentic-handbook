# Test Quickstart

Use the [shared eight-line contract](README.md#shared-rules) and [project brief](project-brief.md). Risk, test and evidence definitions remain in their linked authoritative references.

Follow README.md exactly as a new developer would, in a clean checkout. Inspect commands and environment first; run only authorized, read-only or isolated
commands that need no real credentials and cannot modify shared services. Record each step,
the result, and any confusion. Report every place where the docs were wrong,
incomplete or ambiguous, with a suggested correction.
