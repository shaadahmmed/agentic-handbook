# Write Glossary

Use the [shared eight-line contract](README.md#shared-rules) and [project brief](project-brief.md). Risk, test and evidence definitions remain in their linked authoritative references.

Build docs/glossary.md from the code, database schema, UI text and existing
docs. Find domain terms and detect inconsistent naming (for example the same
concept called user, member and account). Output a table: Term, Meaning,
Name in code, Words to avoid. Then list the inconsistencies you found as a
separate section with suggestions. Do not rename anything in code.
