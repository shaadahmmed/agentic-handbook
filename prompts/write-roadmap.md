# Write Roadmap

Use the [shared eight-line contract](README.md#shared-rules) and [project brief](project-brief.md). Risk, test and evidence definitions remain in their linked authoritative references.

Draft docs/roadmap.md using Now, Next, Later and Non-goals.
[PROJECT BRIEF] [COMMON RULES]

Inputs: open issues and TODO comments (if you can read them), existing plans or
notes, and what I tell you now: Goal for {{PLANNING_PERIOD}}: {{GOALS}};
in progress: {{IN_PROGRESS}}; ideas: {{IDEAS}}; things we will not do:
{{NON_GOALS}}.

Rules: do not invent priorities, dates or commitments. Where I gave none, put
items in Later and mark [CONFIRM]. Each Now item needs an outcome sentence and
a link to an issue or spec if one exists. Add milestone exit criteria only for
milestones I named. Add "Last updated" and "Owner" lines.
