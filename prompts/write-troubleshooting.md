# Write Troubleshooting

Use the [shared eight-line contract](README.md#shared-rules) and [project brief](project-brief.md). Risk, test and evidence definitions remain in their linked authoritative references.

Create docs/troubleshooting.md. Use closed issues, commit messages that
mention fixes, comments marked HACK or WORKAROUND, and CI configuration to find
recurring problems. Format each entry as Symptom, Cause, Fix, with the evidence
file or issue number. Include only items with evidence. Then add a short
section telling agents to append new entries when they solve a new problem.
